# 事件数据接入功能

## 功能概述

为GoldPilot交易看板右侧的信息模块接入真实数据源，包括：
- **经济事件/日历数据**：显示即将发布的重要经济指标
- **首页重要数据/事项**：按美国、北京时间18:00-次日05:00、重要星级筛选今日与本周条目
- **市场快讯/新闻**：实时财经快讯信息

---

## 数据源

### 经济事件/日历
- **主要来源**：汇通财经日历
- **可核对网址**：`https://rl.fx678.com/`
- **方式**：解析汇通财经按日期服务端渲染的经济数据表和财经大事件表
- **备用来源**：配置 `TRADING_ECONOMICS_KEY` 时优先使用 Trading Economics 官方结构化API；汇通不可用时降级为金十结构化接口，再降级为 Trading Economics 网页解析
- **更新频率**：1小时本地JSON缓存
- **原信息核对源**：
  - 汇通财经日历：`https://rl.fx678.com/`

### 市场快讯/新闻
- **来源**：东方财富快讯
- **网址**：`https://kuaixun.eastmoney.com/index.html`
- **方式**：东方财富快讯接口优先，网页解析降级
- **更新频率**：1小时本地JSON缓存

## API接口

### 后端接口

#### 获取经济日历
```
GET /api/events/calendar?date=2026-05-21
```

**参数**：
- `date`（可选）：日期，格式 YYYY-MM-DD，不传则获取今天

**响应**：
```json
{
  "success": true,
  "data": [
    {
      "date": "2026-05-21",
      "time": "20:30",
      "country": "美国",
      "event": "非农就业人数",
      "importance": 3,
      "actual": "25万",
      "forecast": "20万",
      "previous": "22万"
    }
  ]
}
```

#### 获取首页重要数据/事项
```
GET /api/events/important?date=2026-06-05
```

**筛选规则**：
- 国家/地区：美国，或内容中包含美国、美联储、FOMC
- 今日窗口：北京时间00:00-05:00 与 18:00-次日05:00
- 重要数据：四星及以上
- 重要事项：三星及以上
- 本周范围：请求日期起未来7天内的交易日
- 周末处理：周六、周日黄金休市，不读取外部经济日历源，不展示周末数据

**响应**：
```json
{
  "success": true,
  "data": {
    "todayData": [],
    "todayEvents": [],
    "weekData": [],
    "weekEvents": [],
    "sourceLinks": [
      { "name": "汇通财经日历", "url": "https://rl.fx678.com/date/20260605.html", "note": "当前主要数据源，可打开核对原信息" },
      { "name": "Trading Economics", "url": "https://tradingeconomics.com/calendar", "note": "备用日历源" }
    ],
    "filters": {
      "country": "美国",
      "todayWindow": "北京时间18:00-次日05:00",
      "dataImportanceMin": 4,
      "eventImportanceMin": 3,
      "weekDays": 7
    }
  },
  "meta": {
    "source": "live",
    "message": "已按美国、北京时间18:00-05:00和重要星级筛选"
  }
}
```

#### 获取市场快讯
```
GET /api/events/news
```

**响应**：
```json
{
  "success": true,
  "data": [
    {
      "time": "20:52",
      "content": "现货黄金短线拉升，突破2390美元/盎司",
      "hot": true
    }
  ]
}
```

## 使用说明

### 启动服务

1. **安装后端依赖**
   ```bash
   cd goldpilot-backend
   npm install cheerio
   npm install -D @types/cheerio
   ```

2. **启动后端**
   ```bash
   npm run dev
   ```

3. **启动前端**
   ```bash
   cd ../goldpilot-frontend
   npm run dev
   ```

### 数据刷新

- **前端自动刷新**：事件和快讯每1小时刷新一次
- **后端缓存**：实时抓取成功后写入 `goldpilot-backend/data/event-cache.json`
- **手动刷新**：刷新浏览器页面

## 注意事项

### 反爬虫应对
- 设置合理的User-Agent
- 控制请求频率，避免短时间内大量请求
- 如被封禁，可能需要使用代理IP

### 降级处理
- API失败时优先使用1小时内本地JSON缓存
- 实时抓取和缓存都不可用时返回不可用提示；首页不会展示模拟经济日历或模拟快讯
- 首页重要数据/事项为空时仅显示汇通/Trading Economics源信息入口，便于人工核对
- 首页今日/本周重要数据和事项优先使用汇通真实数据；如果筛选后仍为空，表示当前窗口没有符合“美国 + 星级 + 时间段”的真实条目，不再填充模拟内容
- 客户可点击链接统一使用 `rl.fx678.com` 公开页面；金十仅作为后台备用抓取源，不再作为客户入口
- 周六/周日直接返回空日历结果并跳过外部源请求；本周重要数据从下一个交易日继续聚合
- 错误日志记录，便于排查问题

### 维护
- 爬虫方式可能因目标网站结构变化而失效
- 需要定期检查和更新选择器
- 建议后续考虑使用稳定的数据源API
